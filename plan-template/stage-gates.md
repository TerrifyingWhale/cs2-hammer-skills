## S0 启动与边界

- [ ] 已注册/确定 addon 名称与地图名称
- [ ] 已明确玩法类型与范围
- [ ] 已记录命名规则与资产来源

## S1 布局与几何

- [ ] 已完成地图布局草图
- [ ] 已创建基础刷子几何（房间/通道/传送区）
- [ ] 已确定出生点位置

## S2 资产管线

- [ ] 材质（.vmat）：所有贴图已转材质并检查着色器
- [ ] 纹理（.vtex）：需要单独定义的纹理已生成
- [ ] 模型（.vmdl）：所有模型已引用并关联材质
- [ ] 粒子（.vpcf）：所需粒子系统已生成/引用
- [ ] 滤镜（.vpost）：滤镜层已按需配置
- [ ] 声音（.vsndevts）：声音事件已追加（不删除现有代码）
- [ ] 脚本（cs_script）：逻辑已按官方 API 编写

## S3 实体与逻辑

- [ ] 触发器、逻辑实体、传送点已放置并命名
- [ ] 脚本已通过 point_script 挂载
- [ ] 实体属性已对照官方实体列表核实

## S4 光照与氛围

- [ ] 光照实体已放置（天空盒、主光、补光）
- [ ] 滤镜已挂载（post_processing_volume）
- [ ] 粒子/声音已接入场景

## S5 Playtest 与性能

- [ ] 已在游戏内用 `map <mapname>` 测试
- [ ] 无实体/脚本报错
- [ ] 性能在预算内（粒子数、实体数、帧率）
- [ ] 已执行技能完整性检查（如修改过技能）

## S6 发布与归档

- [ ] 已按 Maps Workshop 流程发布
